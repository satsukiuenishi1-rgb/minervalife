# Minerva Life

寮生活を送るミネルバ大学生のための、予定管理と家計管理をひとつにまとめたパーソナルアプリです。

## 主な機能

- **今日** — 今日の予定と今週の予算消化状況を一目で確認
- **予定** — タスク・予定の追加、日付ごとの一覧、完了チェック
- **家計** — 支出/収入の記録、週間予算バー、月間収支、カテゴリ別内訳
- **設定** — 通貨切り替え(ミネルバの都市ローテーションに対応)、週予算の設定、データの書き出し/読み込み

データはブラウザのlocalStorageにのみ保存されます(サーバーには送信されません)。機種変更時は設定画面からバックアップの書き出し/読み込みができます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
```

## 技術構成

- React + Vite
- Tailwind CSS v4
- date-fns / lucide-react
